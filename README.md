# VireMarca Academia Template

Template profissional de site para academias e studios fitness.

## Quick Start

1. Instale dependências: `npm install`
2. Configure `.env.local` com suas credenciais Supabase
3. Execute migrations: `npx supabase db push`
4. Rode dev: `npm run dev`

Acesse: http://localhost:3000
Admin: http://localhost:3000/admin/login

Desenvolvido por VireMarca.
